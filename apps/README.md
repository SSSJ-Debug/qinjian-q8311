# apps · 参考实现

这里放两套"能跑在这个受限设备上"的 App 源码。

它们不是重点 —— **重点是 docs/ 里的方法**。
但有两个真实可运行的例子在手边，比自己从零写要快得多。

---

## guard · 看家

人脸检测抓拍 + 邮件告警。给带前置摄像头的安卓设备用。

**为什么放在这里**：它示范了两件在老旧/定制 ROM 上很实用的事：

1. **完全自绘 UI**（不用 XML 布局、不用 AppCompat），一个 `View.onDraw` 画完整界面，
   124KB 的 APK 就能撑起一个完整的监控台。对内存只有 1~2GB 的设备很友好。
2. **在硬件编码器不可用时退化为软件方案**，并处理了"屏幕强制横屏但面板是竖屏"的坐标问题。

`apps/guard/PATCH-屏幕适配.md` 记录了如何把按 1280 宽设计稿写死的界面适配到 1024 宽的屏幕——
这是很多"别人写的 App 到我设备上显示不全"的通用解法。

**依赖**：无。全部用框架自带的 API，不引入任何第三方库。

**权限**：CAMERA / INTERNET / WAKE_LOCK / WRITE_EXTERNAL_STORAGE / RECEIVE_BOOT_COMPLETED

## tv · 电视直播

HLS 播放 + 多源聚合 + 频道表自动更新。

**为什么放在这里**：它示范了在 **Android 4.4/5.x 的老 TLS 栈**下怎么活：

- 老设备的 `SSLSocket` 默认不协商 TLS 1.2，很多 CDN 直接握手失败
- 解法不是硬改 TLS（改不动），而是**把拉取源的动作外包**：
  让一台 24 小时在线的路由器/小主机定时拉好 m3u，设备只走明文 HTTP 读局域网副本
- 同时保留公网源作为兜底

这个"能联网的设备帮不联网的设备代拉"的套路，对所有老设备都适用。

**依赖**：无第三方库。

## 说明

- 两个 App 都是 **minSdk 19 / targetSdk 19**，能跑在 Android 4.4 ~ 10 上
- 都没有使用 AndroidX，所以不需要 Jetifier，编译环境简单
- 包名保留原样（`com.lm.guard` / `com.lm.tv`），方便你直接替换设备上的版本
